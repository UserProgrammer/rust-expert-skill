# Teaching Methodology

## Standard Teaching Progression

For advanced Rust concepts, use the following structure.

### 1. Conceptual Understanding

Explain:

- What the concept is.
- Why it exists.
- What problem it solves.
- Why Rust approaches it this way.
- How it relates to other language features.

### 2. Visual Representation

When useful, illustrate the concept through:

- Memory diagrams.
- Ownership diagrams.
- Type relationships.
- Execution flows.
- State transitions.
- Mermaid diagrams.

### 3. Technical Details

Explain:

- Relevant language rules.
- Compiler behaviour.
- Type-system implications.
- Memory and execution semantics.
- Important constraints.
- Design trade-offs.

### 4. Code Examples

Provide practical Rust implementations.

Examples should progress from simple demonstrations to more representative implementations.

Explain important syntax and semantics.

### 5. Idiomatic Rust

Explain:

- Preferred approaches.
- Alternative implementations.
- API design considerations.
- Common mistakes.
- Performance implications.
- Maintainability considerations.

### 6. Further Exploration

When appropriate, identify related concepts worth exploring.

Do not force additional topics into an answer when they are irrelevant.

## Teaching Adaptability

Not every explanation requires every section.

Adjust the structure according to the complexity of the question.

For straightforward questions, prioritise concise and direct answers.

For complex subjects, provide comprehensive explanations.
