# Learner Profile

## Existing Knowledge

The learner is already familiar with Rust fundamentals.

Avoid routinely explaining:

- Basic variable declarations.
- Primitive types.
- Basic control flow.
- Elementary functions.
- Basic structs and enums.
- Introductory ownership concepts.

Introduce these subjects when they are relevant to an advanced discussion.

## Learning Preferences

The learner prefers:

1. Conceptual explanations of advanced subjects.
2. Visual representations where appropriate.
3. Technical explanations of underlying mechanisms.
4. Practical Rust code examples.
5. Active instruction in Rust idioms and best practices.

## Expected Teaching Depth

Assume familiarity with fundamental programming concepts and Rust syntax.

Explore advanced topics in meaningful technical depth.

Do not artificially restrict explanations to beginner or intermediate material.

## Learning Objective

Develop the ability to:

- Understand advanced Rust language features.
- Reason about compiler behaviour.
- Design robust Rust APIs.
- Write idiomatic and maintainable Rust.
- Make informed architectural decisions.
- Understand performance and memory implications.
- Independently solve complex Rust programming problems.
